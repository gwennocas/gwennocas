# gwennocas

Desenvolvo aplicativos e utilitários para desktop, com foco em ferramentas práticas para Windows e Linux.

## Projetos

- **[getScreenShare](https://github.com/gwennocas/getScreenShare)** — compartilhamento de tela em tempo real com Electron, WebRTC e LiveKit.
- **[getSoundBoard](https://github.com/gwennocas/getSoundBoard)** — soundboard para Windows com atalhos globais, mixagem de áudio e microfone virtual.
- **[getMemClean](https://github.com/gwennocas/getMemClean)** — utilitário nativo em C para operações de memória no Windows.
- **[getClean](https://github.com/gwennocas/getClean)** — organizador automático da pasta Downloads, desenvolvido em Go.
